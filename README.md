# 🐍 Snake Game

Um clássico jogo da cobrinha feito com HTML, CSS e JavaScript.

![Snake Game](https://via.placeholder.com/600x300?text=Snake+Game)

## 🎮 Como Jogar

- Use as **setas do teclado** (↑ ↓ ← →) para mover a cobra
- Coma as comidas vermelhas para crescer e ganhar pontos
- Não bata nas paredes nem no próprio corpo!

## ✨ Funcionalidades

- Sistema de pontuação
- Recorde salvo no navegador (localStorage)
- Design estilo retro
- Totalmente responsivo
